# AI Work-from-Home Assistant

This project is a localhost-based Streamlit application for real-time posture and distraction monitoring.

## Features
- Posture detection using MediaPipe Pose
- Distraction detection using MediaPipe FaceMesh
- Real-time alerts with delay logic
- Local processing for privacy

## Requirements
Install the required packages using:

```bash
pip install -r requirements.txt


## Run the application
python -m streamlit run app.py


Then open the localhost link shown in the terminal and allow webcam access.
